.. _extend:

Extend the framework
====================

One of the main goals of the new framework is to make it very modular, so users
can write their own objective functions, simulations, minimizers, etc., and
easily plug them into the rest of the machinery of the framework.

In the following pages you'll find some tips on how to write your own pieces of
code and plug them into the new framework.
